# KIVILCIM — demo (yayın kopyası)

Bu depo `kivilcim-runtime` üretim derlemesinin (dist) yayın kopyasıdır. Kaynak geliştirme burada yapılmaz.

- `index.html` / `demo__index.html` — oyun sayfası (klavye + dokunma)
- `demo__game.mjs`, `kivilcim.mjs`, `scenario.mjs`, `attach.mjs` — derlenmiş modüller
- Yayın: GitHub Pages, `main` dalı kök dizin.

Girdi: `ArrowRight`/`ArrowLeft` (veya ekrandaki dokunma şeritleri). Simülasyon deterministiktir; harici paket/CDN yoktur.
